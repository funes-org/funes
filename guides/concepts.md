# Concepts

The pages in this section explain the three ideas that form the core of Funes: events, event streams, and projections. They favor the *what* and *why* over the *how*. If you are new to Funes, or want to understand what each piece is for before you write code, start here.

- [Event](/concepts/event/) — the immutable fact at the heart of the system, written in stone
- [Event Stream](/concepts/event-stream/) — a sequenced group of events under one stream ID
- [Projection](/concepts/projection/) — derive state from an event stream with the interpretations DSL
